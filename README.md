# C Web Engine

A research-driven project exploring C, systems programming,
networking, HTTP, web architecture, and JavaScript from first principles.

## Goals

- Understand C beyond syntax
- Explore Linux and systems programming
- Understand TCP/IP and HTTP at a low level
- Build an HTTP server from scratch
- Implement routing and REST APIs
- Explore authentication and authorization
- Understand JavaScript and browser architecture
- Compare low-level implementations with modern frameworks

## Project Status

🚧 Research in progress

## Learning Approach

Learn → Experiment → Implement → Document → Refactor

## Testing

C Web Engine includes both unit tests and HTTP integration tests.

Run the complete test suite with:

```bash
make test
```
